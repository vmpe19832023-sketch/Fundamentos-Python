# Gestor de Tareas en Consola

Este es un proyecto de aprendizaje de temas básicos de Python, entre ellos uso de etiquetas variables y bucles.

## Conceptos aplicados
* **Variables y tipos de datos:** Manejo de textos y números.
* **Listas:** Almacenamiento dinámico de las tareas del usuario.
* **Condicionales (`if`):** Control de las opciones del menú.
* **Bucles (`while` y `for`):** Ejecución continua del programa y recorrido de listas.

## Cómo ejecutar el proyecto
1. Asegúrate de tener **Python 3** instalado en tu computadora.
2. Descarga el archivo `main.py` de este repositorio.
3. Abre tu terminal en la carpeta del proyecto y ejecuta el siguiente comando:

```bash
python mi_perfil.py
python saludo.py
python contador.py
python contador_for.py
python lista.py
index.html
```
