# Fundamentos de Python

Este es un proyecto de aprendizaje de temas básicos de Python, entre ellos uso de variables y bucles.

## Conceptos aplicados
* **Variables y tipos de datos:** Manejo de textos y números.
* **Listas:** Lista de ciudades de la Región Costa Sur de Jalisco (Solo 6)
* **Condicionales (`if`):** Condicional que define si alguien es menor o mayor de edad o si ingresaron una fecha que aun no sucede.
* **Bucles (`while` y `for`):** Ejecución continua del programa y recorrido de listas.

## Cómo ejecutar el proyecto
1. Asegúrate de tener **Python** instalado en tu computadora.
2. Clona el repositorio.
3. Abre tu terminal en la carpeta del proyecto y ejecuta el siguiente comando:
4. index.html (Este archivo se puede ejecutar desde la carpeta con doble click y se mostrará en el navegador)

```bash
python mi_perfil.py
python saludo.py
python contador.py
python contador_for.py
python lista.py
```
